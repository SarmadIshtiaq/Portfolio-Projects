# AI Governance and GRC Portfolio

A Computer Science graduate (University of the Punjab) focused on AI governance, GRC (Governance, Risk and Compliance), and data governance.

This repository collects practical projects in these areas. Every project uses the same case, so the work forms one connected story. All projects use free and open-source tools.

## Shared case
An AI-assisted loan approval system at a bank. The projects use a public dataset (German Credit, UCI) and an imaginary bank. No real company data is used.

## Projects
| # | Project | Focus | Tools | Status |
|---|---------|-------|-------|--------|
| 1 | AI Governance Program Pack | AI inventory, EU AI Act classification, NIST AI RMF mapping, AI governance policy, model card, bias and explainability testing, model monitoring | CISO Assistant, Fairlearn, IBM AIF360, SHAP, LIME, Model Cards Toolkit, Evidently AI, Giskard | Planned |
| 2 | Data Governance Implementation | Data catalog, ownership, classification, lineage, data quality checks, DPIA, retention policy | OpenMetadata, DataHub, Great Expectations, UK ICO and CNIL DPIA templates | Planned |
| 3 | GRC Risk and Compliance Assessment | Risk register, control library, ISO 27001 control assessment, gap analysis, audit report | CISO Assistant, Eramba Community Edition | Planned |

Each project folder has its own README with the problem, method, analysis, findings, limitations, and references.

## Frameworks and standards used
NIST AI RMF, EU AI Act, ISO/IEC 42001 (public summaries), ISO 27001, NIST Cybersecurity Framework, SOC 2, GDPR, FAIR model

## Skills shown
- AI governance: risk classification, control mapping, model documentation, human oversight, bias testing, explainability
- Data governance: ownership, classification, lineage, data quality, privacy (DPIA)
- GRC: risk assessment, control testing, gap analysis, audit reporting
