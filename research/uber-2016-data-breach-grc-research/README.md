# Project 01: Integrated GRC Framework Design & Implementation

## 1. Project Overview

This project demonstrates the independent design of an Integrated Governance, Risk, and Compliance (GRC) framework using a publicly documented cybersecurity incident as a case study.

The project uses the 2016 Uber data breach as a reference to examine publicly reported security and governance failures and develop a proposed GRC framework addressing relevant organisational risks.

The work is an independent portfolio research and design exercise. It is not an engagement with Uber, an assessment of Uber's internal environment, or a representation of controls actually implemented by Uber.

## 2. Project Objectives

- Analyse a publicly documented cybersecurity incident.
- Identify relevant governance, risk management, and compliance implications.
- Design an integrated GRC operating model.
- Develop a structured risk assessment and treatment methodology.
- Define governance responsibilities and control ownership.
- Design compliance monitoring and evidence management processes.
- Demonstrate selected GRC workflows using Eramba Community Edition, subject to available features.
- Develop supporting assessment workbooks and management dashboards.

## 3. Case Study

**Reference incident:** Uber 2016 Data Breach

The case study will examine publicly available information about the incident, including credential exposure, unauthorised access, data exposure, and breach disclosure.

All incident facts and conclusions will be supported by reliable public sources. Documented facts will be kept separate from independent analysis and proposed recommendations.

## 8. Methodology

The project will follow these phases:

1. Research and validate publicly documented incident facts.
2. Analyse the incident's governance and risk implications.
3. Define the proposed GRC framework and operating model.
4. Develop risk and compliance management artefacts.
5. Explore and demonstrate supported Eramba workflows.
6. Build supporting workbooks and dashboards.
7. Document findings, limitations, and recommendations.
